Bundled:  YES - libopenal.so, inside the APK.

  ---- LGPL RELINKING OBLIGATION, AND HOW IT IS SATISFIED ----

  LGPL v2 differs from the GPL in a way that matters here: it requires that a
  user be able to replace the library with a modified version of their own and
  relink the application against it.

  This distribution satisfies that by DYNAMIC LINKING. openal-soft is built as
  a separate shared object, libopenal.so, and is loaded at runtime by the
  dynamic linker. It is not statically linked into the application binary. A
  user may substitute their own build of libopenal.so.

  Verified: the application library libvanillatd.so carries a DT_NEEDED entry
  for libopenal.so, and libopenal.so ships as a discrete file inside the APK
  under lib/arm64-v8a/. Confirmed with llvm-readelf and by listing the APK.

  openal-soft is unmodified in this distribution.

  Complete corresponding source for openal-soft is available at
  https://github.com/kcat/openal-soft and is pinned in this project's
  repository as a git submodule at a specific commit.
